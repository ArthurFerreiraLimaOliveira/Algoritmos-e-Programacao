Exercício 9 - Conta de Energia

1-Variaveis necessárias

consumo - Consumo de energia no mês kWh
valor - Valor cobrado por cada kWh
contaTotal - Valor total a ser pago na conta de energia

2-Dados adequados

double/real - Todos os valores podem conter casas decimais

3-Pseudocodigo

Var
consumo, valor, contaTotal : real

Início

Leia(consumo)

Escreva("Digite o valor do kWh: R$ ")
Leia(valor)

contaTotal <- consumo * valor

Escreva("Valor da conta: R$ ", contaTotal)

Se (contaTotal > 300) Então
Escreva("Consumo elevado")
Senão
Escreva("Consumo dentro do esperado")

Fim

4-Java

import java.util.Scanner;

public class ContaEnergia {
public static void main(String[] args) {

Scanner leia = new Scanner(System.in);

double consumo, valor, contaTotal;

System.out.print("Digite o consumo em kWh: ");
consumo = leia.nextDouble();

System.out.print("Digite o valor do kWh: R$ ");
valor = leia.nextDouble();

contaTotal = consumo * valor;

System.out.println("Valor da conta: R$ " + contaTotal);

if (contaTotal > 300.0) {
System.out.println("Consumo elevado");
}
else {
System.out.println("Consumo dentro do esperado");
}
}
}
