Exercício 4 - Calculadora de Consumo de Combustível

1-Variaveis necessárias

distancia - Distância percorrida em quilômetros
consumo - Consumo médio do veículo km/l
precoCombustivel - Preço por litro do combustível
litrosGastos - Quantidade total de litros gastos na viagem
custoTotal - Custo total do combustível para a viagem

2-Dados adequados

double/real - Todos os valores podem possuir casas decimais

3-Pseudocodigo

Var
distancia, consumo, precoCombustivel, litrosGastos, custoTotal : real

Início
Escreva("Digite a distância percorrida (km): ")
Leia(distancia)

Escreva("Digite o consumo do carro (km/l): ")
Leia(consumo)

Escreva("Digite o preço do combustível: ")
Leia(precoCombustivel)

litrosGastos <- distancia / consumo
custoTotal <- litrosGastos * precoCombustivel

Escreva("Litros gastos: ", litrosGastos)
Escreva("Custo total: R$ ", custoTotal)


Fim

4-Java

import java.util.Scanner;

public class ConsumoCombustivel {
public static void main(String[] args) {

Scanner leia = new Scanner(System.in);

double distancia, consumo, precoCombustivel;
double litrosGastos, custoTotal;

System.out.print("Digite a distância percorrida (km): ");
distancia = leia.nextDouble();

System.out.print("Digite o consumo do carro (km/l): ");
consumo = leia.nextDouble();

System.out.print("Digite o preço do combustível: ");
precoCombustivel = leia.nextDouble();

litrosGastos = distancia / consumo;
custoTotal = litrosGastos * precoCombustivel;

System.out.println("Litros gastos: " + litrosGastos);
System.out.println("Custo total: R$ " + custoTotal);
}
}
